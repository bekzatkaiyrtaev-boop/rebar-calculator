Порядок работы и алгоритм расчёта

1. Исходные данные
• Населённый пункт — из справочника климатики (обеспеч. 0,92). Под полем автоматически появляется подсказка с зоной влажности, расчётной температурой наружного воздуха и ГСОП для выбранного города — ГСОП при этом не берётся готовым значением из таблицы, а считается по формуле (tint − tот)·zот (формула 2 СН РК) на основе tint, заданной ниже.
• Категория здания по нормам — определяет коэффициенты a, b нормируемого R (табл. 4 СН РК 2.04-07) и Δtн (табл. 2).
• Тип ограждающей конструкции — стена / покрытие / перекрытие и т.п.; определяет αext и группу формулы Rнорм.
• tint, φint — расчётные температура и влажность внутреннего воздуха. По ним автоматически определяются влажностный режим помещения (сухой/нормальный/влажный/мокрый, табл. 1 СП РК 2.04-107) и условия эксплуатации конструкции А/Б (табл. 2), от которых зависит выбор λА или λБ для материалов из справочника.
• Вентилируемая воздушная прослойка — переключает αext на 10,8 Вт/(м²·°C) (прил. Е СП РК); задаётся в карточке «Состав конструкции», под схемой.

2. Состав конструкции (таблица слоёв, снаружи → внутри)
• Материал — можно найти по названию в справочнике (начните вводить название — появится список) либо вписать произвольное название вручную.
• λ — при выборе материала из справочника подставляется автоматически (λА или λБ, в зависимости от условий эксплуатации) и заблокирована от редактирования (🔒); разблокировать может только автор калькулятора.
• Толщина — вводится вручную для каждого слоя. Толщину слоя утеплителя (отмечен радио-кнопкой «Утепл.», подсвечен красным) стоит подбирать, ориентируясь на рекомендацию в блоке «Вывод».
• Кнопками ↑+ / ↓+ / × слои добавляются и удаляются — порядок должен соответствовать реальной стене, снаружи внутрь.
• Ниже таблицы автоматически строится изометрическая схема конструкции — высота каждого слоя пропорциональна его толщине.

3. Нормируемое сопротивление теплопередаче
$$R_{req} = a\cdot ГСОП + b$$ — формула (1), по энергоэффективности (табл. 4 СН РК).
$$R_{min} = \frac{n\cdot(t_в - t_н)}{\Delta t_н\cdot \alpha_в}$$ — формула (2), санитарно-гигиеническое требование (п. 6.2 СН РК), считается только если для категории здания задан Δtн (табл. 2).
$$R_{норм} = \max(R_{req};\ R_{min})$$

4. Фактическое сопротивление теплопередаче
$$R_0 = R_{si} + \sum R_i + R_{se}$$ (прил. Е, формула Е.3 СП РК 2.04-107), где $R_i = \delta_i/\lambda_i$ — термосопротивление каждого слоя.

5. Проверка теплозащиты и рекомендация
Условие Rфакт. ≥ Rнорм. проверяется автоматически. Если оно не выполняется, калькулятор подсказывает минимально необходимую толщину утеплителя — при этом, если у выбранного материала в справочнике заданы стандартные толщины выпуска, подбирается ближайший доступный типоразмер (или комбинация из двух слоёв, если одного недостаточно).

6. Проверка на конденсацию (точка росы)
Точка росы tр определяется по формуле Магнуса из tint/φint. Температура внутренней поверхности τsi при расчётных зимних условиях сравнивается с tр — конденсата на поверхности быть не должно (п. 6.3.1 СП РК). Дополнительно строится профиль температуры по толщине конструкции — он показывает температуру на каждой границе слоёв, чтобы увидеть риск конденсации не только на поверхности, но и внутри толщи (например, в утеплителе, если пароизоляция расположена неверно).

7. Сохранение и печать
Кнопка «Сохранить данные расчёта» выгружает введённые значения в файл .json — его можно позже загрузить обратно для правки и пересчёта. Кнопка «Печать» в блоке «Вывод» формирует отчёт со всеми формулами, таблицами и итоговым заключением.

Ограничения
• Справочники материалов и климатики — общие для сайта; если нужного материала или города нет в списке, впишите параметры вручную.
• При подборе толщины утеплителя из типоразмеров материала комбинация предлагается максимум из двух слоёв — для укладки в 3 и более слоёв считайте вручную.
• Сейсмические, ударные и прочие воздействия, не связанные с теплотехникой, не учитываются.
