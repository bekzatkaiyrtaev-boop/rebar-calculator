Область применения калькулятора

Геометрия проёма и опирания
• Ширина проёма в свету Lпр: 300…4320 мм
• Толщина стены/перегородки: 65…142 мм (кирпич/камень) или 100…142 мм (газоблок) — верхний предел задан опиранием на L 125 x 8, максимальный профиль в сортаменте
• Глубина опирания: табличный минимум 100/150/200 мм (по ширине проёма), автоматически увеличивается при недостаточной несущей способности кладки под опорой

Профиль перемычки
• Только одиночный равнополочный уголок, ГОСТ 8509-93, диапазон L 50 x 5…L 125 x 12
• Сталь S235 / S275 / S355
• Парные уголки, швеллеры и другие профили — не рассчитываются

Нагрузка
• Учитывается только собственный вес кладки (треугольная эпюра, арочный распор) — или нагрузка, заданная вручную равномерной
• Нагрузка от перекрытия, стяжки, отделки и т.п. — не учитывается автоматически (можно задать вручную через режим «равномерная нагрузка», уже включив в неё всё нужное)
• Высота треугольного клина кладки ограничена Lпр/2 (упрощённая модель арочного распора)

Материал кладки
• Марка камня: М50…М200; марка раствора: М10…М150
• Виды: кирпич керамический/силикатный (полнотелый и пустотелый), газоблок D600/D700, ракушечник — либо свои показатели K, α, β
• Формула прочности кладки fk — по EN 1996-1-1 §3.6.1.2, коэффициенты K/α/β для группы 1 — из Национального приложения РК (точные), для группы 2 и ракушечника — по базовой таблице EN с обобщёнными показателями степени (ориентировочно)
• Плотность штукатурки учитывается только в весе кладки (доп. нагрузка) — на fk и смятие не влияет; 1800 кг/м³ — типовое значение для цементно-песчаной штукатурки, откорректируйте под фактический состав

Что НЕ учитывается (ограничения модели)
• Условия применимости формулы fk (§3.6.1.2(2)): fb ≤ 75 МПа (общий раствор) / ≤ 50 МПа (тонкий слой); fm ≤ 20 МПа или ≤ 2fb; толщина стены равна ширине/длине камня (без продольного шва вдоль стены); коэфф. вариации прочности камня ≤ 25% — калькулятор эти границы не проверяет автоматически
• Коэффициент формы кирпича δ (EN 772-1) — марка камня принимается уже как нормализованная прочность, без поправки на реальные пропорции конкретного кирпича
• Группа камня (1/2/3/4) определяется по названию в списке, а не по фактической пустотности и размеру пустот — при нестандартной перфорации сверяйте по факту применяемого материала
• Повышающий коэффициент β при смятии кладки под опорой (EN 1996 §6.1.3(2), для группы 1) — не применяется, расчёт всегда идёт по консервативному варианту §6.1.3(3), без учёта эффективной длины распределения нагрузки
• Двухосный (косой) изгиб уголка — учтён консервативно через Wmin (ось v-v), без точного разложения по осям u-u/v-v
• Сейсмические, ударные и особые (аварийные) воздействия — не учитываются
• Предельный прогиб — не задан Еврокодом жёстко (EN 1993-1-1 §7.2.1 отсылает к проекту), выбирается пользователем

Если условия объекта выходят за эти рамки — расчёт носит ориентировочный характер, требуется проверка вручную или по другому профилю (парный уголок, швеллер и т.п.).
