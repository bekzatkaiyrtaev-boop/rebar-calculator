Пром. полосы зоны D (при h > 2b)
Наветренная стена при h > 2b делится на нижнюю и верхнюю полосы высотой b, а промежуток между ними — на это число равных полос (7.2.2(1), Рисунок 7.4; число полос выбирает инженер, норма не задаёт его жёстко)
Ветер набегает на грань шириной b (наветренная стена, зона D). Боковые стены — грани здания, параллельные направлению ветра, длиной d (зоны A, B, C). Противоположная грань шириной b — подветренная стена, зона E.
▶Дополнительные параметры давления внутреннее давление · площадь элемента
Значения ниже приняты по умолчанию как для здания без доминирующего фасада (ворота/проёмы приняты закрытыми, п. 7.2.9(3)) — обычный случай для большинства зданий. Менять их нужно, только если у здания есть заведомо доминирующий проём и это специально проверяется как особая расчётная ситуация.

Коэфф. внутр. давления, cpi,max
Площадь элемента, A (м²)
По умолчанию 10 м² — расчёт на всю конструкцию (cpe,10). Для промежуточных площадей 1–10 м² cpe определяется логарифмической интерполяцией между cpe,1 и cpe,10 (7.2.1(1))
h/d > 5 — по п. 7.2.2(2) Примечание 2 СП РК EN 1991-1-4 при таком соотношении результирующую ветровую нагрузку следует определять через коэффициенты усилия (7.6–7.8, 7.9.2), а не через коэффициенты давления зон A–E. Результаты ниже посчитаны по зонам A–E формально, но для здания с такими пропорциями (высокое и узкое) этот метод не является нормативно корректным — используйте коэффициенты усилия.
Расчётная схема по текущим b, d, h
Суммарное давление (с учётом внутреннего) — зоны D, A, B, C, E
Это давление принимается в расчётах конструкций и каркаса — wnet = we − wi, наиболее неблагоприятная комбинация cpi для здания без доминирующего фасада (7.2.9(6), 5.2(3); значения cpi,min/cpi,max задаются в блоке «Дополнительные параметры давления»).
▶Внешнее давление на стены (зоны D, A, B, C, E)
D — наветренная стена, E — подветренная, A/B/C — боковые стены (параллельные ветру). we,10 — для расчёта конструкции и её элементов площадью ≥ 10 м² (стеновые панели, ригели фахверка). we,1 — для мелких элементов и креплений площадью ≤ 1 м² (кляммеры, крепёж обшивки). Знак «−» — разрежение (отсос от поверхности), «+» — давление на поверхность.
▶Давление для площади элемента 7.2.1(1) — нужно только для мелких элементов/крепежа
cpe(A) — логарифмическая интерполяция между cpe,1 и cpe,10 для промежуточной площади элемента (1–10 м²).

Область применения калькулятора

Что считает калькулятор
• Ветровое давление на вертикальные стены прямоугольного в плане здания — зоны D (наветренная), A, B, C (боковые), E (подветренная) по СП РК EN 1991-1-4:2005/2011 §7.2.2 и НТП РК 01-01-3.1(4.1)-2017
• Пиковый скоростной напор qp(z) по высоте — с учётом типа местности (Табл. 4.1) и орографии
• Зона D делится на высотные полосы при h > b (§7.2.2(1), Рисунок 7.4) — число промежуточных полос задаёт пользователь
• Коэффициенты cpe — по Табл. 7.1 в редакции приказа №216-НҚ от 30.12.2021 (значения зафиксированы, не зависят от h/d — актуальная казахстанская редакция, отличается от «ванильного» EN 1991-1-4)

Внутреннее давление и площадь элемента
• Блоки «Суммарное давление» и «Площадь элемента» рассчитаны для здания без доминирующего фасада — ворота, крупные проёмы и т.п. приняты закрытыми (п. 7.2.9(3): доминантные проёмы в предельном состоянии по несущей способности рассматриваются закрытыми, случай с открытыми проёмами — отдельная особая расчётная ситуация по EN 1990)
• Коэффициент cpi по умолчанию — наихудшее из +0,2/−0,3 (п. 7.2.9(6), Примечание 2), это стандартный подход для типового здания без явно доминирующего проёма
• Если у здания есть заведомо доминирующий проём и его специально нужно проверить как особую расчётную ситуацию — эта методика (формулы 7.1/7.2) в калькуляторе не реализована

Что НЕ учитывается (ограничения модели)
• Здания с h/d > 5 — по норме считаются через коэффициенты усилия (§7.6–7.8, 7.9.2), а не через коэффициенты давления зон A–E — калькулятор эту границу не проверяет автоматически
• Отсутствие корреляции давления между наветренной и подветренной стороной (§7.2.2(3), понижающий коэффициент до 0,85 для суммарной силы) — не применяется, здесь считаются только локальные давления по зонам, не итоговая сила на здание
• Точный орографический коэффициент c₀(z) для сложного рельефа (Приложение А.3, холмы/обрывы) — не вычисляется, только ручной ввод при отключённой «ровной местности»
• Давление на кровлю (зоны F/G/H/I, покрытия любой формы) — не считается, только вертикальные стены
• Динамический (резонансный) отклик гибких конструкций и конструкционный коэффициент cscd (Раздел 6) — не учитываются, здание принимается жёстким

Если условия объекта выходят за эти рамки — расчёт носит ориентировочный характер, требуется проверка вручную.
