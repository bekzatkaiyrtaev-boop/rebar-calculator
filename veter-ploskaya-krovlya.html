Ветер набегает на кровлю со стороны грани шириной b. Зона F — угловые участки у наветренного края, G — остальная часть краевой полосы, H — средняя полоса, I — внутренняя часть кровли (наиболее удалена от края).
▶Дополнительные параметры давления внутреннее давление · площадь элемента
Значения ниже приняты по умолчанию как для здания без доминирующего фасада (ворота/проёмы приняты закрытыми, п. 7.2.9(3)) — обычный случай для большинства зданий. Менять их нужно, только если у здания есть заведомо доминирующий проём и это специально проверяется как особая расчётная ситуация.
Коэфф. внутр. давления, cpi,min
Здание без доминирующего фасада — принимается наихудшее из cpi,min/cpi,max (7.2.9(6), Примечание 2)
Коэфф. внутр. давления, cpi,max
Площадь элемента, A (м²)
По умолчанию 10 м² — расчёт на всю конструкцию (cpe,10). Для промежуточных площадей 1–10 м² cpe определяется логарифмической интерполяцией между cpe,1 и cpe,10 (7.2.1(1))
hp/h > 0,10 — Табл. 7.2 СП РК EN 1991-1-4 задаёт коэффициенты давления только до hp/h = 0,10. Ниже значения приняты консервативно по последней строке таблицы (hp/h = 0,10), это не является строгим нормативным расчётом для более высоких парапетов — дополнительно рассмотрите указания п. 7.4 (парапеты и присоединённые элементы) и проверьте расчёт вручную.
Расчётная схема план кровли по текущим b, d, h
Суммарное давление (с учётом внутреннего) — зоны F, G, H, I
Это давление принимается в расчётах конструкций кровли — wnet = we − wi, наиболее неблагоприятная комбинация cpi для здания без доминирующего фасада (7.2.9(6), 5.2(3); значения cpi,min/cpi,max задаются в блоке «Дополнительные параметры давления»).
▶Внешнее давление на кровлю (зоны F, G, H, I)
F — угловые зоны у наветренного края, G — остальная краевая полоса, H — средняя полоса, I — внутренняя часть кровли (значение приведено для обоих знаков cpe, т.к. вблизи нуля знак может меняться). we,10 — для расчёта конструкции и её элементов площадью ≥ 10 м² (настил, прогоны). we,1 — для мелких элементов и креплений площадью ≤ 1 м² (кляммеры, крепёж кровельного покрытия). Знак «−» — разрежение (отсос от поверхности), «+» — давление на поверхность.
▶Давление для площади элемента 7.2.1(1) — нужно только для мелких элементов/крепежа
cpe(A) — логарифмическая интерполяция между cpe,1 и cpe,10 для промежуточной площади элемента (1–10 м²).

Область применения калькулятора

Что считает калькулятор
• Ветровое давление на плоскую кровлю — зоны F (угловые), G (краевая), H (средняя), I (внутренняя) по СП РК EN 1991-1-4:2005/2011 §7.2.3, Табл. 7.2, для острого края и края с парапетом
• Пиковый скоростной напор qp(ze=h) — с учётом типа местности (Табл. 4.1) и орографии
• Для парапета — линейная интерполяция коэффициентов между строками таблицы по отношению hp/h (узловые значения 0; 0,025; 0,05; 0,10)
• Зона I — учтены оба знака cpe = ±0,2, т.к. вблизи нуля знак давления может меняться

Внутреннее давление и площадь элемента
• Блоки «Суммарное давление» и «Площадь элемента» рассчитаны для здания без доминирующего фасада — ворота, крупные проёмы и т.п. приняты закрытыми (п. 7.2.9(3))
• Коэффициент cpi по умолчанию — наихудшее из +0,2/−0,3 (п. 7.2.9(6), Примечание 2)

Что НЕ учитывается (ограничения модели)
• Скруглённый и мансардный край кровли (отдельные строки Табл. 7.2 с r/h и углом α) — не реализованы, только острый край и парапет
• Скатные, вальмовые, многопролётные и цилиндрические кровли (§7.2.4–7.2.10) — не считаются, только плоская кровля
• Парапеты с hp/h > 0,10 — коэффициенты приняты по последней строке таблицы (hp/h = 0,10) консервативно, это не строгий расчёт по норме
• Дополнительная сила трения на поверхности кровли (§7.5, для протяжённых кровель) — не учитывается
• Динамический (резонансный) отклик гибких конструкций и конструкционный коэффициент cscd (Раздел 6) — не учитываются, здание принимается жёстким

Если условия объекта выходят за эти рамки — расчёт носит ориентировочный характер, требуется проверка вручную.
